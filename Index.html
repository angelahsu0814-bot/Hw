一、 研究題目規劃

題目一：AI 算力浪潮下的 K 型復甦：台灣半導體出口對製造業薪資與貨幣總量 (M2) 之動態溢出效應

研究重點：探討半導體出口暴增對國內金融面貨幣總量 (M2) 的推動作用，以及對實體經濟中不同產業薪資結構的動態傳導與不對稱外溢效果。

題目二：全球 AI 供應鏈衝擊與台灣經濟韌性：基於結構向量自回歸 (SVAR) 之電子零組件出口動態傳導

研究重點：建立 SVAR 模型，將 AI 算力需求視為外生衝擊，分析半導體出口波動對物價 (CPI)、貨幣供給 (M1B/M2) 及總薪資的衝擊反應路徑與經濟調整韌性。

二、 研究假說與傳導機制

假說一：動態溢出與貨幣積累

  • H1a：半導體出口年增率成長對 M2 具有顯著正向影響，且存在 2-3 個月的傳導延滯。
  • H1b：出口獲利外溢至總薪資的效果高度集中於高科技製造業，拉大與傳統產業之薪資差距。
傳導路徑： AI需求衝擊 → 電子零組件出口 → 順差與外匯流入 → 央行國外資產 & Corporate Deposits → M2總量升高 → 科技業薪資擴散

假說二：SVAR 結構衝擊與實體回應

  • H2a：電子零組件出口衝擊能帶來持續 6-12 個月的實體薪資正向效應，且短期內通膨 (CPI) 壓力可控。
  • H2b：M1B 對外生出口衝擊的敏感度高於 M2，反映資產市場的交易性貨幣需求熱絡。

四、 Python 資料清洗與時序分析模組

下方為對 AREMOS CSV 數據進行預處理、計算 YoY 與平穩性檢驗的標準 Python 程式碼：

import pandas as pd
import numpy as np
from statsmodels.tsa.stattools import adfuller

def clean_aremos_data(filepath):
    # 讀取 AREMOS CSV (常見編碼 cp950)
    df = pd.read_csv(filepath, encoding='cp950')
    df.rename(columns={df.columns[0]: 'Date'}, inplace=True)
    
    # 轉換時間格式 (例如 2020M01 -> 2020-01-01)
    df['Date'] = df['Date'].astype(str).str.replace('M', '-').str.replace('/', '-')
    df['Date'] = pd.to_datetime(df['Date'])
    df.set_index('Date', inplace=True)
    
    # 數值型態清洗與插補
    for col in df.columns:
        df[col] = pd.to_numeric(df[col].astype(str).str.replace(',', ''), errors='coerce')
    df.ffill(inplace=True)
    return df

# 計算 YoY (%) 並進行 ADF 檢定
def analyze_series(df):
    yoy = df.pct_change(12) * 100
    yoy.dropna(inplace=True)
    for col in yoy.columns:
        p_val = adfuller(yoy[col])[1]
        print(f"變數 [{col}] ADF p-value: {p_val:.4f}")
    return yoy
